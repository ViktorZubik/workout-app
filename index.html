Как обновить Apps Script
1. Открой Apps Script своей таблицы
2. Замени весь код (кнопка ниже скопирует новый)
3. Сохрани и задеплой заново: «Развернуть» → «Управление развёртываниями» → ✏️ → выбери «Новая версия» → Сохранить
4. URL остаётся тем же. Лист «Группы мышц» создастся автоматически для справочника упражнений. Формат журнала менять не нужно: история загрузится из колонок «Дата», «Группа мышц», «Упражнение», «№ подхода», «Повторы», «Вес (кг)», а новые тренировки будут сохраняться туда же.
